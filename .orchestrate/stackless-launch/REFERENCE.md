# stackless-launch reference (for workers)

Durable discovery artifact — do not re-walk the repo for basics; extend with code pointers as needed.

## Current state (v0.1.0, no git tags yet)

- **CLI verbs:** `up`, `down`, `verify`, `status`, `list`, `logs`, `check`, `daemon` (hidden). No `init`, `adopt`, or `doctor`.
- **Agent output:** global `--json`; errors use `schema_version: 1` with stable `code`, `remediation`, optional `context`. NDJSON progress on stderr during `up --json`. See `README.md` Agent output section, `crates/stackless/src/error.rs`, `crates/stackless/src/output.rs`.
- **Substrates:** `local`, `render`, `vercel`, `fly`, `netlify` registered in `crates/stackless/src/substrates.rs`. README provider matrix still has fly/netlify unchecked.
- **Release:** `cargo-dist` 0.32.0 in `dist-workspace.toml`; `.github/workflows/release.yml` autogenerated; workspace version `0.1.0` in root `Cargo.toml`. No GitHub releases published yet.
- **Fixtures:** `fixtures/hello` uses invalid `example.invalid` repo; `fixtures/pgdemo` needs Docker postgres; `fixtures/smoke/*` for gated live cloud smokes; `fixtures/smoke/site/index.html` marker `stackless-smoke-ok`.
- **Smokes:** `mise run smoke-{vercel,render,cloudflare,fly,netlify}`; cloudflare provisions integrations on `--on local`.
- **ARCHITECTURE.md:** `init --from` documented as not yet shipped.

## Conventions

- Read `CLAUDE.md`, `ARCHITECTURE.md`, `docs/SCHEMA.md` before core edits.
- Error codes: match patterns in `stackless-core/src/def/error.rs`, `engine/error.rs`, substrate `SubstrateFault`.
- Tests: hermetic via `mise run ci`; live smokes gated in `smoke.yml`.
- Feature branches: `cursor/<descriptive-name>-1f13`.

## Non-goals

Secret-blind egress, fleet mode, new providers (per VISION.md sequencing).

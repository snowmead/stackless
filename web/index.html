stackless.toml 
[stack]
name = "demo"

[integrations.clerk]
provider = "clerk"
app_name = "${stack.name}-${instance.name}"

[services.web]
source = { repo = "https://github.com/you/app", ref = "main" }
root_origin = true
health = { path = "/", contains = "ok" }
env = { CLERK_SECRET_KEY = "${integrations.clerk.secret_key}" }

  [services.web.vercel]
  framework = "vite"
  build = "npm run build"

[services.db]
source = { repo = "https://github.com/you/app", ref = "main" }
health = { path = "/health", contains = "ready" }

  [services.db.local]
  run = "docker run --rm -p $PORT:5432 postgres:16"
$ stackless up --name demo --on vercel --json stackless down demo --json

Why

Parallel agents need isolated stacks. Existing tools leave the lifecycle incomplete.

Dozens of isolated, abandonable stacks per day. Containers run processes. IaC owns state. Provider CLIs mint resources. None own naming, wiring, health proof, cost hygiene, and verified death as one contract.

stackless is that contract: the lifecycle layer between an agent and the stack it works on.

Parallel agents

One toml. Many named instances.

One stackless.toml. Many named instances. Prefer a git worktree per agent. Or snapshot a dirty tree with --source + --dirty (local only — cloud rejects it; commit and push instead).

Lifecycle

Three verbs.

  1. up

    Create or resume a named instance. Health-gated: success only after every service passes through the public origin. Substrate fixed at create via --on.

  2. verify

    Run the proof contract and renew the lease. A provisioned stack is unfinished until verified.

  3. down

    Verified teardown. Refuses success while anything that costs money or holds state remains. Expired leases reap the rest.

For agents

Stdout is the envelope.

Every command is non-interactive. Always pass --json. Branch on error.code, never on prose. stderr carries NDJSON progress during up. 

{
  "ok": true,
  "name": "demo",
  "url": "http://127.0.0.1:8741",
  "substrate": "local"
}

Install

Install once.

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/snowmead/stackless/releases/latest/download/stackless-installer.sh | sh
stackless check stackless.toml --on local --json
